# Downtown Dating Website

A modern, responsive dating website frontend built with HTML, CSS, and JavaScript.

## Features

- Clean, modern UI with responsive design for all devices
- Interactive elements with smooth animations
- Registration and login functionality (frontend only)
- Testimonial slider
- Animated sections on scroll
- Modal dialogs

## Project Structure

```
Downtown_Dating/
│
├── index.html            # Main HTML file
├── css/
│   └── styles.css        # CSS styles
├── js/
│   └── script.js         # JavaScript functionality
└── img/                  # Image assets (placeholder)
```

## How to Use

1. Clone or download the repository
2. Open `index.html` in your web browser

## Functionality

- **Registration Form**: Allows users to sign up (frontend only, no backend processing)
- **Login Modal**: Accessible via the login button in the navigation bar
- **Testimonial Slider**: Navigate through user testimonials with the arrow buttons
- **Responsive Design**: Fully responsive layout that works on mobile, tablet, and desktop

## Development

This project is built with:
- HTML5
- CSS3 (with custom properties and flexbox)
- Vanilla JavaScript

## Notes

This is a frontend-only implementation. In a real-world scenario, you would need to:
- Implement a backend server
- Add proper authentication
- Create a database for user information
- Implement actual matching algorithms
- Add more features like messaging, profile management, etc.
